# Launches Mockups

Launches prototypes (epics under [LPD-50024](https://liferay.atlassian.net/browse/LPD-50024)).

- `launches-mockup-clay.html`: Launches, Pages and CMS Content (Clay)
- `launches-mockup-custom.html`: same, hand-rolled CSS
- `page-editor-launch-selector.html`: Page Editor with Live/Launch context selector
- `launch-item-selector.html`: reusable Launch item selector modal ([LPD-115340](https://liferay.atlassian.net/browse/LPD-115340)); the New button is covered by [LPD-116332](https://liferay.atlassian.net/browse/LPD-116332)
- `page-status-flow.html`: Launch and Page draft status flow
- `content-page-status.html`: Content Page and Object Entry status simulator
