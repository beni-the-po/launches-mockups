Page Status Flow

How a Page moves between statuses while it's edited, added to a Launch, and published — and which actions are available at each point. Editing never happens on the published version: it always happens on a draft, and how that draft is resolved decides the Page's status.

Statuses

DraftThe Page has an open Main Draft, not tied to any Launch.
Launch DraftThe Page has a draft tied to a Launch.
PublishedThe live version.
PendingOnly on seed data ("Products") — no action leads to it yet.

Transitions

Click a status to see what leads into it and what comes next.

FromActionToNotes
Editing a Main Draft Keep as Main Draft Draft Only one Main Draft per Page; a new one replaces the old one.
Editing a Main Draft Publish (with confirmation) Published Standalone publish, only from the Main Draft. The version goes up (4.0 → 5.0).
Editing a Main Draft Add to a Launch Launch Draft The Page keeps its Main Draft and also gets a draft for that Launch.
Launch Draft Save Launch Draft Keeps the draft open and tied to the Launch.
Launch Draft Ready to Publish Launch Draft The Page's status doesn't change. It marks the Page's entry in the Launch as "Ready to Publish" — what the Launch's Publish/Schedule check looks at.
Launch Draft The Launch publishes automatic Published When the Launch is published manually or at its scheduled time.
Published Edit again A new open draft Starts the cycle again. A Page can have one Main Draft plus one draft per Launch at the same time.

Open questions

!Launch publish doesn't update the Page. In the mockup, publishing a Launch changes its elements to Published, but the Page itself still shows "Launch Draft" in the Pages list — the diagram says it should become Published.
!Pending has no way in. No action leads to it — either it needs a transition, or the "Products" seed data should use a different status.
!Failed Launch is undefined for Pages. Nothing says what happens to a Page whose element failed. Under the no-rollback rule it should stay Launch Draft, but that isn't stated anywhere.
